## Deskripsi Aplikasi
TabungKu merupakan aplikasi berbasis Flutter yang menampilkan halaman Ringkasan Tabungan menggunakan widget dasar Flutter.

## Teknologi yang Digunakan
- Flutter
- Dart
- Android Studio

## Cara Menjalankan Aplikasi

Jalankan perintah berikut pada terminal:

```bash
flutter pub get
flutter run
```
